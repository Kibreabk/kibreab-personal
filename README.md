# Kibreab Kebede — Premium Multi-page Personal Website

A static, responsive personal website built for GitHub Pages.

## Pages

- `index.html` — Home, animated hero and Bible verse carousel
- `books/index.html` — Currently Reading and Finished Books
- `portfolio/index.html` — CV preview modal, GitHub and project cards
- `photography/index.html` — My Shots, Moments and high-resolution lightbox
- `about/index.html` — Personal interests, faith, family, cinema, sports and travel
- `social-media/index.html` — Social profiles and contact details

## Important source files

- `assets/css/styles.css` — all shared and page-specific styling
- `assets/js/main.js` — navigation, animation, modal, lightbox and carousel logic
- `assets/js/verses.js` — editable Bible verse data
- `assets/files/` — downloadable CV files
- `assets/images/photos/full/` — 3840-pixel-long-edge high-resolution viewing copies

No framework, build command, package manager or Jekyll theme is required. Upload the files and publish from the `main` branch root.

## Guides

- `DEPLOYMENT_GUIDE.md` — publish on GitHub Pages
- `CONTENT_EDITING_GUIDE.md` — update text, verses, projects, photos, and links
- `QA_REPORT.md` — completed structural, interaction, and responsive checks
- `PHOTO_QUALITY_NOTE.md` — image-processing details and limitations
- `CREDITS.md` — public-domain book-scan sources
