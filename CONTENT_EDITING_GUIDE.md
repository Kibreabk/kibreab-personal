# Content editing guide

## Bible verses

Edit `assets/js/verses.js`. Each verse is one object with `category`, `text`, and `reference`. The Home-page dots and slide count are created automatically.

## Home-page text

Edit the hero content inside the `<section class="home-hero">` block in `index.html`.

## Books

Edit `books/index.html`. Cover files are stored in `assets/images/books/`. The cards intentionally contain no outbound shopping or reading links.

## Portfolio and CV

Edit project cards in `portfolio/index.html`. Replace the two files in `assets/files/` whenever the CV changes, keeping the same filenames so the preview and download buttons continue to work.

## Photography

- Fast gallery images: `assets/images/photos/thumbs/`
- Large page images: `assets/images/photos/display/`
- Lightbox images: `assets/images/photos/full/`

Gallery titles, captions, alt text, and file paths are in `photography/index.html`.

## Social links and contact details

Edit `social-media/index.html`. The same footer links also appear on the other HTML pages.

## Design

Shared colors, typography, spacing, responsive rules, and components are in `assets/css/styles.css`. Shared interaction code is in `assets/js/main.js`.
